# JAVA

**Java Runtime Enviroment or JRE** - It contain Java libraries and JVM needed to run the Java programs on system's OS

**Java Development Kit or JDK** - It contain tools such as Java Compiler necessary for writing and compiling Java Source Code to byte codes. It includes *JRE* needed to execute a byte codes.

    JDK--[ JRE--[ JVM ]]

There are two variant of JDK

1. OpenJDK -> Free and open-source implementation of the JDK under the GNU General Public License. It can be downloaded, modified, and redistributed without cost, including for commercial purposes. It is developed and maintained by a community of developers - including Oracle, Red Hat, and others and releases are more frequent, with support typically provided until the next version is released. This can make it somewhat unstabble, although bugs are resolved quickly.

2. Oracle JDK -> Oracle JDK requires a commercial paid license for production use. Oracle, parent company of Java, provides direct long term support and updates for Oracle JDK releases. It includes features like Flight Recorder and Java Mission Control that are not available in OpenJDK

If we want to write Java Programs, we need JDK. If we want to only run Java applications, we only need JRE

**Java Enterprise Edition - J2EE, Java EE or Jakarta EE** - Set of tools and libraries to create enterprise-class applications (different from JDK)
